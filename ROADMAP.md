# WNYAtlas roadmap

The roadmap keeps promising ideas visible without overloading the first release.

## Milestone 1 — Foundation

- [x] Establish project identity and editorial standard
- [x] Scaffold Next.js, TypeScript, and Tailwind CSS
- [x] Create a responsive map-first homepage
- [x] Add typed starter records
- [x] Document a PostGIS-ready data direction
- [ ] Install dependencies and confirm production build
- [ ] Publish the first preview

## Milestone 2 — Working atlas

- [ ] Replace the illustrated placeholder with MapLibre
- [ ] Add accessible site markers and detail panels
- [ ] Create filters for site type, evidence status, and cleanup method
- [ ] Build individual site pages
- [ ] Expand to 25 carefully sourced anchor records
- [ ] Add citations and an evidence panel to every record

## Milestone 3 — Spatial database

- [ ] Provision PostgreSQL/PostGIS
- [ ] Adopt migrations and controlled vocabularies
- [ ] Import seed records
- [ ] Add geometry for sites, corridors, waterways, and management areas
- [ ] Add source provenance and retrieval dates
- [ ] Establish automated backups

## Milestone 4 — Historical layers

- [ ] Historic dumps and landfills
- [ ] Industrial sites and ownership timelines
- [ ] Brownfields and former uses
- [ ] Cleanup remedies, caps, monitoring, and institutional controls
- [ ] Drinking-water systems, intakes, outfalls, and documented events
- [ ] Watersheds, waterways, and restoration projects
- [ ] Measured, reported, and modeled air-quality history

## Later research experiences

- [ ] Timeline slider
- [ ] Then-and-now aerial comparison
- [ ] Material-flow stories: where waste came from and where it went
- [ ] Watershed journey view
- [ ] Downloadable data and printable maps
- [ ] Public correction and source-submission workflow

## Not in scope for the founding build

- Unsupported health claims
- Automated causal conclusions based on proximity
- Unverified community memories presented as fact
- A large unsourced import simply to increase the marker count
